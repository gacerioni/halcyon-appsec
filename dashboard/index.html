How a fix ships

Scanner findings→Triage into campaigns→Devin session per repo→Fix + tests→Trivy · Semgrep in CI→PR / MR→Human review→Canary 10%→Smoke→100%
  • Devin never merges. Every PR above is open until an engineer approves it.
  • "Fixed" means the scanner ran again on the PR head and the finding is gone, with tests passing.
  • Findings a PR leaves open are listed in the PR body with the reason. They need a product decision, not a scanner.
